# NGS Calculator

Инструмент для планирования экспериментов секвенирования нового поколения (NGS). Работает полностью в браузере, без установки.

🔗 **[Открыть калькулятор онлайн](https://ttnlsc.github.io/sequencing-calculator/)**

---

## Возможности

### Планирование ёмкости ячейки
- 4 режима расчёта:
  - **Размер панели + Покрытие** — для WGS, WES, таргетных панелей
  - **Ампликоны + Покрытие** — для ампликонных панелей (1 ампликон = 1 рид)
  - **Данные на образец** — когда известен требуемый объём в Мб/Гб
  - **Риды на образец** — когда протокол задан в млн ридов
- Автоматический перевод циклов в длину рида (SE / PE)
- Учёт качества: % дупликатов и % ≥Q30 для расчёта *полезного* выхода

### Калькулятор молярности и разведения
- Конвертер **нг/мкл → нМ** с учётом длины фрагмента (формула: `nM = (ng/µL × 10⁶) / (660 × length_bp)`)
- Расчёт разведения: введите объём стока и получите объём буфера для целевой концентрации

### Подготовка к запуску (GeneMind / Геноскан 4000)
- Пошаговая памятка: денатурация → первое разведение (4 nM → 20 pM)
- Калькулятор второго разведения: выберите загрузочную молярность (1.4–4.4 pM), получите объёмы 20 pM библиотеки и Hybridization Solution для финальных 1500 мкл
- Легко расширяется на другие платформы (архитектура готова)

### Интерфейс
- Автоматическая тёмная/светлая тема (`prefers-color-scheme`)
- Полностью адаптивный дизайн — удобно с телефона и планшета

## Как пользоваться

### 1. Расчёт ёмкости ячейки
1. Выберите **платформу** → **инструмент** → **Flow Cell** → **циклы**
2. Укажите **режим секвенирования** (SE / PE) → длина рида рассчитается автоматически
3. Выберите **режим планирования**:
   - *Размер + Покрытие*: введите размер таргета (Мб/Гб) и желаемое покрытие (X)
   - *Ампликоны*: укажите кол-во ампликонов и покрытие на каждый
   - *Данные*: введите требуемый объём на образец (Мб/Гб)
   - *Риды*: введите млн ридов на образец
4. (Опционально) Откройте **Доп. параметры** и укажите % дупликатов / % Q30 для более реалистичной оценки
5. Нажмите **«Рассчитать ёмкость»**

💡 **Примеры**:
### 2. Конвертация молярности
1. В блоке **«Калькулятор молярности»** введите:
   - Среднюю длину фрагмента (п.н.)
   - Концентрацию библиотеки (нг/мкл)
2. Нажмите **«Перевести в нМ»** → получите молярность

### 3. Расчёт разведения
1. После конвертации (или вручную) укажите:
   - Концентрацию стока (нМ)
   - Целевую концентрацию пула (нМ)
   - Объём стока для разведения (мкл)
2. Нажмите **«Рассчитать разведение»** → получите:
   - Объём буфера для добавления
   - Итоговый объём смеси
   - Фактор разведения (×)

### 4. Подготовка к запуску (GeneMind)
1. Выберите платформу **GeneMind** → инструмент **GenoLab M / Геноскан 4000**
2. В появившемся блоке ознакомьтесь с памяткой по денатурации и первому разведению
3. Выберите загрузочную молярность (1.4–4.4 pM)
4. Нажмите **«Рассчитать второе разведение»** → получите объёмы для финальной смеси 1500 мкл
