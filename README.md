# 🧬 Калькулятор секвенирования

Простой и быстрый инструмент для планирования экспериментов NGS. Позволяет рассчитать выход данных, фактическую длину ридов и оптимальное количество образцов для мультиплексирования на flow cell.

🔗 **[Открыть калькулятор онлайн](https://github.com/ttnlsc/sequencing-calculator)**

## ✨ Возможности
- 📊 Расчёт выходного объёма данных в гигабазах (Гб)
- 📏 Автоматический перевод циклов в длину рида (SE / PE)
- 🧫 Планирование мультиплексирования: сколько образцов поместится на ячейку при заданном покрытии и размере целевой области
- 💻 Работает полностью в браузере
- 🌓 Адаптивный дизайн + автоматическая тёмная тема
- 📱 Можно добавить на главный экран телефона как PWA-приложение

## 🚀 Как пользоваться
1. Выберите **платформу** и **инструмент** (например, `Illumina` → `NextSeq 2000`)
2. Укажите **Flow Cell** (например, `P2`)
3. Выберите **пресет циклов** (например, `300`) → длина рида рассчитается автоматически
4. Введите **размер целевой области** в Гб и **желаемое покрытие** (X)
5. Нажмите `Рассчитать` → получите макс. количество образцов и остаток данных

💡 **Примеры для быстрого старта:**
| Задача | Размер (Гб) | Покрытие (X) |
|--------|-------------|--------------|
| WGS человека (GRCh38) | `3.2` | `30` |
| Экзом (WES ~50 Мб) | `0.05` | `100` |
| Панель генов (~1 Мб) | `0.001` | `500` |
